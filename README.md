# Tractions public website

Only this folder belongs in the public `abdullah1772/Tractions` website repository. Do not upload the parent app directory, local database, credentials, logs, exports or backups.

This is a buildless static site. Enable GitHub Pages from branch **main**, folder **/(root)**. Intended URLs after publication:

- Website: `https://abdullah1772.github.io/Tractions/`
- Privacy: `https://abdullah1772.github.io/Tractions/privacy.html`
- Terms: `https://abdullah1772.github.io/Tractions/terms.html`
- Icon: `https://abdullah1772.github.io/Tractions/icon.png`

The expected URLs above are not proof of deployment. Check each returns successfully after Pages publishes. Website ownership verification files from TikTok can be placed beside index.html using the exact filename TikTok provides, then committed and redeployed.

The site contains no API keys, live analytics, remote fonts, sign-in forms or tracking scripts. The chart is explicitly illustrative. TikTok is described as in development; the local dashboard is not hosted by GitHub Pages. Policy descriptions are based on the current local implementation. Review and update them before publishing changes to data practices or opening the app to other users.
